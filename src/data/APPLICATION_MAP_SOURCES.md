# Application dashboard map attribution

Administrative boundary data from geoBoundaries gbOpen, retrieved 5 October 2026. Original upstream per-country licenses apply to the map data and its derived geometry. Ghana geometry is redistributed under CC BY-SA 2.0 (https://creativecommons.org/licenses/by-sa/2.0/); Nigeria and Zambia under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/); Kenya source is public domain. This does not change the license of the application code.

- **Kenya** (2020): RCMRD GeoPortal, Africa GeoPortal. Public Domain. Boundary ID: KEN-ADM1-32016919. Source: https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/KEN/ADM1
- **Nigeria** (2022): GRID3. Creative Commons Attribution 4.0 International (CC BY 4.0). Boundary ID: NGA-ADM1-27671186. Source: https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/NGA/ADM1
- **Ghana** (2021): Open Street Map. Creative Commons Attribution-ShareAlike 2.0. Boundary ID: GHA-ADM1-69750345. Source: https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/GHA/ADM1
- **Zambia** (2020): Zambia Data Hub. Creative Commons Attribution 4.0 International (CC BY 4.0). Boundary ID: ZMB-ADM1-6923714. Source: https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/ZMB/ADM1

Changes: simplified coordinates with Shapely (0.012 degree tolerance, preserve topology), rounded to four decimals, and generated representative points inside each region. Regional names are matched to the existing registration lists: Tharaka → Tharaka Nithi, Ghana's Region suffix removed, and Zambia's Muchinga → existing Muchiga Province spelling. Original names are not changed in the registration form. These are overview boundaries, not authoritative legal boundaries or applicant locations. Bubble area represents application counts, not population-adjusted rates. Missing/unmatched locations remain in the region table and are counted separately.
